## 关于我

网上叫我「杨不易呀」，也有人叫「程序员杨不易」，GitHub 上的 ID 是 `yangbuyiya`。本职是全栈开发，主攻 Java 生态：后端从 Spring Boot 到各类中间件，前端写过 Vue、React 和 uni-app，习惯把一个功能从环境搭建一路拆到能跑的 DEMO。

写技术文章是另一条主线。在腾讯云开发者社区开有「杨不易呀」专栏，累计 280+ 篇文章、35 万+ 阅读，拿过社区 2023 年度「最受欢迎创作者」和「优秀创作者」；也受邀在腾讯技术创作特训营分享过《小白如何成为优秀的技术创作者》。《从零玩转微信支付》是我第一个专栏，后来又写了《从零玩转系列之 MCP AI 理论 + 项目实战开发你的 MCP Server》——不写「概念科普」，只写能照着做出来东西的长文。
